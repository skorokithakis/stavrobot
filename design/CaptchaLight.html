Solve the Signal captcha

Signal asks for a captcha before it links the bot's number.

  1. Open the captcha page. It opens in a new tab.signalcaptchas.org
  2. Solve the captcha.
  3. When you see "Open Signal", right-click that link and copy its address.
  4. It starts with signalcaptcha://
Status states (shown above the Submit button)
Empty inputPaste the signalcaptcha:// value first.
SubmittingSending the captcha to Signal
Success
Accepted. Signal is linking the number. You can close this page.
Failure
Signal rejected the captcha: it has expired. Solve a new one.
