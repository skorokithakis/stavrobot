Stavrobot components

Part 1: tokens, type, buttons, form controls, state, navigation

All styles are in sb.css. Put class="sb" on the body. Light is the default; dark applies when the OS asks for it (prefers-color-scheme: dark). There is no theme switch.

Never write a hex value in a page. Use a token. This board shows the light theme; the board on its right shows the same parts in dark.

01 Colour tokens

Amber stays the identity in both themes. Amber is only a fill (buttons, logo, checked boxes). For amber text, links and icons, use accent-text: it is darker in light mode, so it meets AA. Ratios are against surface unless the row says other.

06 Inputs, all states

Every input has a visible label. Field errors put a danger border on the input and a message under it, which tells the user how to fix it. Link the message with aria-describedby and set aria-invalid="true".
