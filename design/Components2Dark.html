Feedback, callouts, lists, tables, panels, code, loading, confirm, chat

Same classes, same file (sb.css). States that you cannot see in a static picture (hover, focus) are shown with the helper classes is-hover and is-focus. In the app, the real :hover and :focus-visible do the same.

01 Inline feedback

Put it on the right of the button that caused it (under the button on mobile). Success goes away after 4 seconds. An error stays until the next action. Use role="status" for progress and success, role="alert" for errors.

Desktop: a 420 px panel on the right of the table, as high as the table; only the panel body scrolls. 10 Loading and load errors

12 Chat parts

User messages are on the right in an amber tint; bot messages are on the left and support Markdown. Each message has a sender label and a time. Code blocks scroll sideways inside the bubble. The input grows from 44 px to 160 px, then scrolls. Enter sends; Shift+Enter makes a new line. While a reply is pending, the input and Send are disabled and the thinking dots show.
